# Game Feel

**الهدف:** الحركة يبقى ليها وزن وتستجيب. الميكانيك نفسها متتغيرش.

> خطة Phase 2 الأصلية اتنقلت لـ `docs/phase-2-plan.md` وهي خلصت.
> النتايج والقرار في `docs/phase-2-shadow-prototype.md`.

**الظل مش بيتأثر بأي حاجة هنا** — ده بالظبط مكسب الطريقة ب: اللي اتسجّل هو
النتيجة مش المدخل، فأي تعديل في السرعة أو الجاذبية أو الـ coyote time مش
بيبوّظ ولا تسجيلة. فيه تست بيثبّت إن الإعادة مطابقة تماماً، من غير tolerance.

## اللي خلص

| الحتة | مكانها |
|---|---|
| `Locomotion` واحدة للمشهدين (تسارع، احتكاك، لف أسرع، نط) | `lib/game/character/locomotion.dart` |
| جاذبية النزول أسرع من الطلوع + سرعة سقوط قصوى | `WarayaConfig.fallGravity` |
| نطة متغيرة الارتفاع — دوسة = نطّة، ضغط مستمر = نطة كاملة | `WarayaConfig.jumpCutFactor` |
| coyote time + jump buffer | `WarayaConfig.coyoteSeconds` / `jumpBufferSeconds` |
| اهتزاز كاميرا على الهبوط القوي | `lib/game/screen_shake.dart` |
| interpolation للظل (كان مؤجل من Phase 2) | `ShadowFigure.alpha` |
| أنيميشن جري + وطي | `lib/game/character/figure.dart` |
| صوت: خطوات، نطة، هبوط، زرار، باب | `lib/audio/` |
| الأصوات نفسها — مولّدة بسكربت، مش مسجّلة | `tools/sfx.py` |

**مهم:** `WarayaConfig.gravity` (جاذبية الطلوع) **متغيّرتش بقصد** — ارتفاع النطة
اللي المشهد الرمادي متقاس عليه معتمد عليها، وتغييرها بيعيد تصميم الألغاز من
غير ما حد ياخد باله.

## الصوت

مفيش صوتي في الفريق، فالأصوات **مولّدة بسكربت** زي ما الصور مقصوصة بسكربت:

```sh
python3 tools/sfx.py --verify     # يكتب assets/audio/ ويطبع وصف كل صوت
```

متعدّلش الـ wav بإيدك — هي build output. عايز صوت مختلف؟ عدّل الدالة بتاعته
في السكربت وشغّله تاني. ولو جبت أصوات حقيقية بعدين، بدّل الملفات بنفس
الأسامي والكود مش هيحس.

مفيش كود في اللعبة بيكلم مكتبة صوت. كله بيكلم `AudioOut`، وليها تنفيذ حقيقي
وتنفيذ صامت — نفس منطق الـ input abstraction. التستات صامتة تلقائياً.

**سؤال مفتوح لـ Phase 4:** الظل دلوقتي **مبيعملش صوت**. ظل بخطوات واطية
ورا اللاعب هيقلب الإحساس ناحية المطاردة أكتر — ده قرار تصميم مش feel، فمتأجل.

## طريقة التظبيط

كل الأرقام ثوابت مسماة فوق بعضها في `lib/game/config.dart`. غيّر الرقم واعمل
**hot reload (`r`)** — مفيش rebuild ومفيش restart. ده الـ loop.
